# lifecycle-orchestrator

Agent-driven system to orchestrate the end-to-end product development lifecycle — from product requirements and technical design to automated testing and multi-stage change request (CR) workflows.

## ✨ What it does

* 🧠 PM agent: generates requirements and specs
* 🏗️ Design agent: creates technical design
* 💻 Dev agents: implement features
* 🧪 Test agents: generate and execute tests
* 🔁 CR workflow: manages multi-stage approvals and releases

## 🚀 Why this exists

Most tools handle isolated parts of the lifecycle. This project connects them into a single, agent-driven flow that automates the entire journey from idea to production.
